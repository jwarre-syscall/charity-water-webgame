# World Wide Water

A responsive, browser-based mini game inspired by the World Wide Water wireframe and the charity: water brand usage guide.

## Play

Open \`index.html\` in a browser, or enable GitHub Pages for this repository and publish from the branch root.

Catch 12 clean blue drops in 60 seconds. Move with the left/right arrow keys or A/D, or use the on-screen buttons on a phone. Avoid muddy drops; three hits end the round. Pause with the in-game button or Escape.

## Files

- \`index.html\` — page structure and game interface
- \`styles.css\` — responsive layout, game scenery, and visual styling
- \`script.js\` — movement, drop spawning, collision, score, timer, lives, pause, and replay

## Design notes

The game keeps the wireframe's title, water scene, clean/dirty drops, score, and lives. It uses a brighter charity: water-inspired yellow, water blue, navy, and mint palette, with a spacious layout and hopeful tone. The watering can and landscape are drawn with inline SVG and CSS so the prototype does not require extra image assets.

This is an educational game concept and is not an official charity: water product or donation mechanism.
